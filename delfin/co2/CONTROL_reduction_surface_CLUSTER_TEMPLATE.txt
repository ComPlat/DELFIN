# CONTROL.txt template — CO2 reduction surface (hyperpotential profile)
#
# Place this file as CONTROL.txt in a NEW job folder under calc/<jobname>/,
# fill the [PLACEHOLDERS], then start the run the usual way (delfin submit /
# /orca submit). DELFIN generates CO2_coordination/CONTROL.txt itself from
# these co2_* keys (chain_setup transfers every co2_-prefixed key).
#
# Workflow the run executes, in order:
#   1. MANTA builds the complex from co2_manta_smiles
#   2. CO2 coordination (place_co2_general)  -> complex_aligned_with_CO2.xyz
#   3. adduct_flow: xTB preopt + coordination check + OCCUPIER (PBE0 opt)
#      -> the ORCA-optimized adduct geometry
#   4. reduction_surface chain from that geometry:
#      - station co2  : GFN2-xTB preopt (rs_run_xtb)
#      - station co2h : PBE0/def2-SVP opt (rs_run_dft) — xTB DESTROYS the
#                       protonation motifs (proven on 81-105_87, charge +1/+2)
#      - station co2h2: PBE0/def2-SVP opt (one H per O)
#      - station co   : H migration -> split BEFORE opt, body and free H2O
#                       optimized separately, energies summed
#      - NEB-TS between consecutive stations when reduction_surface_ts=true
#   5. automatic profile plot reduction_surface/reduction_surface_profile.png
#      (reference = station 1 = M...CO2 = 0)
#
# Reference run: calc/81-105_87_sub_irss_auto (same SMILES family).
