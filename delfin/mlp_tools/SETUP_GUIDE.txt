===========================================================================
  MLP Tools Setup Guide — ML Potentials in DELFIN
===========================================================================

ML Potentials (MLPs) provide DFT-quality energies and forces at a
fraction of the computational cost.  DELFIN integrates three backends:

  ANI-2x    — Fast, accurate for organic molecules (H,C,N,O,S,F,Cl)
  AIMNet2   — Broader element coverage (14 elements), charge support
  MACE-OFF  — State-of-the-art equivariant potential, broad coverage


1. QUICK INSTALL
---------------------------------------------------------------------------

Option A — Via DELFIN installer (recommended):

  bash delfin/mlp_tools/install_mlp_tools.sh

  By default installs ANI-2x + AIMNet2.  To also install MACE-OFF:

  INSTALL_MACE=1 bash delfin/mlp_tools/install_mlp_tools.sh

Option B — Via pip extras:

  pip install delfin-complat[mlp]

Option C — Individual packages:

  pip install torchani          # ANI-2x
  pip install "aimnet[ase]"     # AIMNet2 (aimnetcentral)
  pip install mace-torch        # MACE-OFF

Option D — Via DELFIN Dashboard:

  Settings tab → "Install mlp_tools" button


2. GPU ACCELERATION
---------------------------------------------------------------------------

All three backends support CUDA GPU acceleration.  Install PyTorch
with CUDA support for significant speedups on large systems:

  pip install torch --index-url https://download.pytorch.org/whl/cu121

Then use device="cuda" when creating calculators:

  calc = create_calculator("ani2x", device="cuda")


3. ELEMENT COVERAGE
---------------------------------------------------------------------------

  Backend    Elements supported
  ─────────  ──────────────────────────────────────────
  ANI-2x     H, C, N, O, S, F, Cl  (7 elements)
  AIMNet2    H, B, C, N, O, F, Si, P, S, Cl,
             As, Se, Br, I  (14 elements)
  MACE-OFF   Most organic elements (broad coverage)

  IMPORTANT: None of these support transition metals.
  For transition metal complexes, use xTB or ORCA instead.


4. USAGE IN PYTHON
---------------------------------------------------------------------------

Basic single-point energy:

  from delfin.mlp_tools.calculators import create_calculator
  from ase import Atoms

  atoms = Atoms('H2O', positions=[[0,0,0], [0.96,0,0], [0.24,0.93,0]])
  calc = create_calculator("ani2x")
  atoms.calc = calc
  energy = atoms.get_potential_energy()   # eV
  forces = atoms.get_forces()            # eV/Angstrom

Convenience functions:

  from delfin.mlp_tools.calculators import single_point, optimize_geometry

  # Single point
  result = single_point(atoms, backend="aimnet2", charge=0)
  print(result["energy"])  # eV

  # Geometry optimization
  result = optimize_geometry(atoms, backend="ani2x", fmax=0.05, steps=200)
  print(result["converged"], result["energy"])

  # Rank multiple structures
  from delfin.mlp_tools.calculators import rank_structures
  ranking = rank_structures(list_of_atoms, backend="aimnet2")
  best_idx, best_energy = ranking[0]

For charged molecules (only AIMNet2):

  calc = create_calculator("aimnet2", charge=-1, mult=1)

6. ORCA Extopt (Mlp-Driven Geometry Optimisations)
---------------------------------------------------------------------------

The ExtOpt infrastructure (ORCA manual 4.1.10) lets ORCA run a geometry
optimisation (Opt, OptTS, NEB-TS, GOAT, IRC, relaxed scan) with energies
and gradients supplied by an MLP instead of the DFT method.  DELFIN's
wrapper module lives at delfin/mlp_tools/orca_extopt.py; the executable
entry point is created by the installer at <mlp_tools root>/bin/delfin-mlp-extopt.

Setup:

  bash delfin/mlp_tools/install_mlp_tools.sh   # creates bin/delfin-mlp-extopt
  source delfin/mlp_tools/env.sh               # puts bin/ on PATH

ORCA input (%method block):

  ! Opt ExtOpt
  %method
    ProgExt "delfin-mlp-extopt"
    Ext_Params "--backend aimnet2 --device cpu"
  end

Ext_Params is forwarded verbatim to the wrapper.  Backends: any name
accepted by delfin.mlp_tools.calculators.create_calculator; use
"aimnet2" for charged systems or elements beyond H,C,N,O,S,F,Cl.
The Python selection (mlp_preopt / mlp_optimize) does not need the
wrapper -- only ORCA ExtOpt runs do.

AIMNet2 notes for ExtOpt:
  - 14 elements (H,B,C,N,O,F,Si,P,S,Cl,As,Se,Br,I) and charge/mult
    support; the wrapper passes charge/multiplicity from the extinp.
  - The AIMNet2 model file ("aimnet2", alias of aimnet2-wb97m-d3_0) is
    fetched on first use by the aimnet package (aimnetcentral); run one
    single-point once before a long ExtOpt job to populate the cache.

Model-weights cache (AIMNET_CACHE_DIR):
  DELFIN resolves one cache directory for all MLIP entry points
  (calculator factory, ExtOpt launcher, SLURM jobs) in this priority:

    1. AIMNET_CACHE_DIR             - upstream override; wins if set
    2. DELFIN_MLP_CACHE_DIR         - DELFIN key for shared caches
    3. $HOME/mlip-envs/aimnet-cache - used only if it already exists
    4. ~/.cache/aimnet              - upstream default (created on demand)

  On clusters with a read-only $HOME (~/.cache not writable) setting
  AIMNET_CACHE_DIR is required, e.g.:

    export AIMNET_CACHE_DIR=$HOME/mlip-envs/aimnet-cache

  A not-writable or uncreatable cache raises a clear error naming the
  override key. Existing weights are reused; nothing is re-downloaded.
  Licence note: the AIMNet2 weights (aimnet2_wb97m_d3_0.pt, hosted on
  the aimnetcentral GCS bucket) carry no explicit licence document;
  the aimnet software is MIT. Public availability is not a licence
  grant - cite the model paper in publications (Anstine/Zubatyuk/
  Isayev, Chem. Sci. 2025, DOI 10.1039/D4SC08572H).


7a. ORCA-MLIPS EXTERNAL PROVIDERS (Phase C)
---------------------------------------------------------------------------

  Four registry backends run as orca-mlips ProgExt plugins INSIDE ORCA
  (kind=external_cli): orca_mlips_aimnet2, orca_mlips_uma,
  orca_mlips_orb, orca_mlips_mace.  They are NOT ASE-calculator
  backends: the ASE factory refuses them on purpose.

  Install (per user approval only; separate venv recommended):

    pip install orca-mlips[aimnet2]      # or [uma] / [orb] / [mace]

  Use: name the provider as the backend of an ExtOpt input; its plugin
  executable becomes ProgExt directly.  Plain "aimnet2" aliases a
  DIFFERENT plugin - always use the orca-mlips-<name> executable.

    ! Opt ExtOpt
    %method
      ProgExt "orca-mlips-aimnet2"
      Ext_Params "--device cpu"
    end

  Licence gates (registry license_note): UMA weights are gated on
  Hugging Face, terms UNVERIFIED; MACE foundation checkpoints are
  Academic Software License (non-commercial).  A licence-restricted
  provider stays flagged in mlp_list_backends even when installed.
  Software orca-mlips is MIT.  Public availability of weights is not a
  licence grant - verify before any download.


7. CHOOSING A BACKEND
---------------------------------------------------------------------------

  Use case                              Recommended backend
  ────────────────────────────────────  ───────────────────
  Fast screening of organic molecules   ANI-2x
  Charged molecules                     AIMNet2
  Halogenated / P / Si / Se compounds   AIMNet2
  Highest accuracy needed               MACE-OFF (large)
  GPU available, large batch            Any (all support CUDA)
  Transition metals                     NOT SUPPORTED — use xTB

  ANI-2x is typically fastest for small organic molecules.
  AIMNet2 covers more elements and handles charges.
  MACE-OFF is most accurate but also heaviest.


8. COMMON ISSUES
---------------------------------------------------------------------------

Problem: ModuleNotFoundError: No module named 'torchani'
Fix:     pip install torchani

Problem: RuntimeError: CUDA out of memory
Fix:     Use device="cpu" or reduce batch size

Problem: ANI-2x error "Element not supported"
Cause:   Molecule contains elements outside H,C,N,O,S,F,Cl
Fix:     Switch to AIMNet2 or MACE-OFF

Problem: AIMNet2 import error
Fix:     pip install "aimnet[ase]"

Problem: torch not found
Fix:     pip install torch
         For GPU: pip install torch --index-url https://download.pytorch.org/whl/cu121


9. ENVIRONMENT VARIABLES
---------------------------------------------------------------------------

  DELFIN_MLP_TOOLS_ROOT   Override mlp_tools root directory
  INSTALL_ANI2X            Set to 0 to skip ANI-2x   (default: 1)
  INSTALL_AIMNET2          Set to 0 to skip AIMNet2   (default: 1)
  INSTALL_MACE             Set to 1 to install MACE   (default: 0)
  FORCE_REINSTALL          Set to 1 to force reinstall
