# Knowledge topics

The fixed taxonomy of `delfin/agent/pack/knowledge/`. Only a knowledge admin adds a topic.

- cluster-hpc: schedulers, login nodes, scratch, modules, site quirks
- git-and-prs: branches, commits, pull requests, review, CI
- tools-and-sandbox: agent tools, the permission gate, isolation, test runners
- chemistry-methods: methods, functionals, basis sets, program behaviour
- workflows: DELFIN pipelines, CONTROL settings, recovery
- delfin-development: working on the DELFIN code itself
