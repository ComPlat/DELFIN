# Office Mode

Administrative work: documents, tables and data, in the user's own
folder. One agent, no role routing, no chemistry.

The calc-search and ORCA-manual tools are not available in this mode.
That is the point: an administrative question must not be answered with
methodology, and a spreadsheet in a department folder is not a
calculation to be interpreted.

Best for:
- Reading, checking and editing spreadsheets
- Filling PDF forms and Word templates, single or as a series
- Producing letters, reports and tables to hand on
- Reconciling two lists and reporting where they disagree
- Collecting, sorting and converting files

Not for:
- Anything about ORCA, DFT, calculations or the methodology manual —
  use Code mode in the DELFIN checkout for that.
- Editing source code. That is Code mode.
